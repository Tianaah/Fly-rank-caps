## Project Overview

This is a frontend capstone project built as part of an AI-assisted development track.

## Tech Stack

- React
- JavaScript
- Vite
- Tailwind CSS
- Git
- GitHub

## Development Conventions

- Use functional React components.
- Use clear and descriptive component names.
- Keep components small and reusable.
- Use semantic HTML where appropriate.
- Follow consistent formatting and indentation.
- Avoid unnecessary duplication.
- Keep styling organized using Tailwind CSS.
- Do not introduce additional libraries without a clear reason.
- Keep the code accessible and responsive.

## Git Conventions

Use Conventional Commits.

Examples:

- `feat: add navigation`
- `fix: correct mobile layout`
- `docs: update README`
- `refactor: simplify component structure`

## AI Development Guidelines

Before making significant changes, explain the proposed approach.

Prefer simple solutions that fit the existing project structure.

Do not modify unrelated files.

When completing a task, summarize what was changed and identify any files that were modified.
